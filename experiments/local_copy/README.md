# Higher-order directionality and physical copy-source tests

Three independent experiments, October 28, 2026. **No decipherment claim**.

## 1. Reproduce the original prospective glyph experiment

The previously reported ROC-AUCs 0.913 (A) and 0.906 (B) originated in exploratory JavaScript. The [original Python implementation](../phonotactics/evaluate.py) is now run **end-to-end on the source ZL3b and IT2a transcriptions** via `.github/workflows/full-replication-and-copy.yml` job `phonotactics`. It reports AUC and average precision for degree-only, degree+glyph length, and degree+length+glyph-bigrams, with an inner 50%/20% fitting split and final 30% evaluation split. Never claim a verified result until the Python job has completed; source SHAs are archived. This is one order-specific split, not genuine composition chronology.

## 2. Higher-order forward/backward conditional prediction with independent folios

`experiments/higher_order_direction/evaluate.py` uses **four disjoint held-out folio blocks**, with each folio assigned once to a test fold. Remaining folios form that fold's training set. Exact page identities never cross train and test. Folds are blocked by observed folio order, but **do not assert manuscript writing order**.

Fit unigram, position-only, hierarchical position-aware bigram/trigram/4-gram models on both normal and reversed sequences. Conditional probability is normalized by recursive interpolation: base token unigram, line start/second/early/middle/late/penultimate/end position distribution (smoothed to unigram), then up to three preceding tokens, with training-only smoothing selected by 20% inner folios over a broader 4/16/64/256/1024 grid.

The model receives **complete held-out line length**, but NOT held-out word identities as features. All baselines see the same known line length. (The full line length is not generally known to an online writer, so this must be interpreted as conditional reconstruction, not an incremental writing model.) Forward and backward share the same train-only word budget within a fold and a pooled `<UNK>` category for rare/unseen forms. Real versus position-preserving shuffled training is evaluated on the **identical** held-out words and line positions.

All page-conditional log losses, token coverage, positional strata, and folio-block bootstrap 95% intervals for directional gains are recorded. Compare a **reverse-specific benefit over shuffling**, not merely `NLL(right) < NLL(left)`. English Austen and Darwin serve as known-language controls. Pseudo sentence boundaries in English differ from Voynich physical lines.

## 3. Direct nearby horizontal/vertical copy and edit exposures

`experiments/local_copy/evaluate.py` tests **token-by-token access to actual earlier printed words**, not just static edit-graph degree. It separately measures:
- Same-line prior five tokens vs following five tokens (future placebo);
- Immediately previous line / immediately next line, at corresponding token index ±2 (vertical copying);
- Previous two lines / next two lines in the same column window;
- Prior/future five lines, any column;
- Exact repetition vs **exactly one canonical EVA glyph edit**, including insertions, deletions and substitutions (excluding exact repetition);
- All targets vs **first occurrence of each word type on its page**, preventing ordinary repeated same-page words from dominating the test.

The null randomly permutes word tokens **within each physical folio** and within first/middle/last positional bins, preserving each folio's word multiset, line lengths and start/end position marginals. For each metric report observed source exposure rate, mean of 150 shuffle trials, excess percentage points, one-sided permutation p, and earlier-minus-later **directional excess** compared with the same placebo difference under permutation. This is a **positional co-occurrence test**, not yet a parameter-fitted copy-generation likelihood model. A positive local excess does not establish literal copying; topic, common inflections and edit-rich word families may contribute. Physical preceding text is not necessarily historical production order. For strong evidence, require **directional** effects beyond shuffled null and repeated independent blocked splits.

Include both English texts and the public *sample* generated by the Timm/Schinner 2020 self-citation code. This is a single published generator configuration, NOT a full generative simulation across varied parameters. The generator itself explicitly allows choosing source words from nearby earlier text and similar line positions: see its public `PROPERTIES.md`.

## Run and reproducibility

```bash
pip install -r requirements.txt
python experiments/phonotactics/evaluate.py --zl data/ZL3b-n.txt --it data/IT2a-n.txt --out results/phonotactics
python experiments/higher_order_direction/evaluate.py --zl data/ZL3b-n.txt --austen data/1342-0.txt --darwin data/1228.txt --out results/higher_order_direction
python experiments/local_copy/evaluate.py --zl data/ZL3b-n.txt --austen data/1342-0.txt --darwin data/1228.txt --generated data/timm_generated.txt --permutations 150 --out results/local_copy
```

The CI workflow fetches original texts, reports SHA256 checksums, and stores all outputs as separate 30-day artifacts. Unit fixtures test exact one-glyph adjacency, page-composition-preserving permutations and nonoverlapping folio folds.

## Key confounds to follow up

1. Folio section, hand, quire, transcription source and script variants, especially Currier A/B transitions.
2. The match-rate denominator depends on having earlier/later lines and the line lengths. Source and future placebo windows must be compared conditionally.
3. Timm's generator includes source-word retrieval from *different pages*, not only lines within a page. The current test does not evaluate cross-page retrieval due to uncertain historical order.
4. Glyph distance depends on EVA compound segmentation; use alternative tokenizations and image-reviewed disputed readings.
5. This proximity test measures source availability **without** assigning each observed token to its actual source. A following model should compare copy/edit choice likelihood with and without local previous-context exposure, with frequency/orthographic/position baselines.
6. A 4-gram model is not a complete grammar model. Compare PPM, Kneser-Ney, finite-state morphology, and class-based word transitions after checking this conditional baseline.

The objective is a falsifiable test against a *specific local source-selection mechanism*, not a claim that Voynich is a hoax, a natural language, or written backwards.
